# Karan Chugani: Portfolio

Personal site showing physics and computing projects, built with React and Vite.

## Projects

- Black Hole Accretion Simulator (live): real-time 3D particle dynamics in Three.js
- Exoplanet Detection: finding Kepler-22b's orbit from raw NASA data
- Gravitational Wave Analyser: in progress, using LIGO open data

## Run locally

```
npm install
npm run dev
```
